# hatsu_ino

> **hatsu** (初, first sound) + **ino** (Arduino) — the first sound your car makes.

An Arduino-based JDM car melody box that plays an audio file when you start your car, then enters deep sleep until the next start.

## Boards

| Version | Description |
|---|---|
| [v0](boards/v0/) | A JDM car melody box that plays a WAV audio file when you start your car. |
| [v1](boards/v1/) | A JDM car melody box that plays an MP3 file when you start your car — built around a DFPlayer Mini module instead of driving audio from the Nano itself. |
